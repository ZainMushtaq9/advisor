## 4. Findings and corrections

### Correction applied by the coordinator (C-01)
- **WEBSITE_MODULE_SPECIFICATION.md — agent-registry claim corrected.** The file repeatedly stated the agent registry covered "Agents 1–6 only" and that forecasting/valuation/risk/etc. functions were "NOT YET REGISTERED" with "Phase 16/Phase 22" references. This contradicts AGENT_REGISTRY.md, which registers all 18 agents plus the orchestrator, and contradicts the canonical 30-phase list (Phase 22 is Investment recommendation engine; backend/API foundations are Phase 05, frontend integration is Phase 28). A dated coordinator correction note was added to the top of that file, superseding those claims and directing readers to the 18-agent registry. The UNVERIFIED status in that file now correctly applies to external data feeds, not to registry entries. No other content in that file was changed, and no sibling file was edited.

### Findings that are NOT failures of Phase 1, but gates on later phases
- **G-01 — Macro/statement/announcement/news machine-use UNVERIFIED.** SECP, SBP, PBS, Finance Division, World Bank, IMF, FRED machine interfaces; structured financial-statement source; announcement PDF extraction; news feed. Phases 08, 09, 10, 14 are fully gated; Phases 11, 15, 16, 17, 22, 26 are partially dependent and must proceed on verified PSX data alone with gaps labelled. Next action: Phase 2/Phase 10 read-only verification per source (direct docs read, per-series metadata), never by inventing an endpoint.
- **G-02 — Software licences UNVERIFIED in detail.** ZERO_COST_REGISTER.md confirms no paid dependency is adopted, but LICENSE files were not read for many libraries (Python/Node, TypeScript, Pydantic, Uvicorn, SQLAlchemy, Alembic, SQLite, pandas, NumPy, scikit-learn, statsmodels, PyTorch, PyMuPDF, pypdf, Tesseract, pytest, Playwright, Git, Docker Engine, GitHub Free limits). Next action: Phase 2 setup gate — record each LICENSE file; if any item required payment, it stops and is replaced, never silently adopted.
- **G-03 — Sector taxonomy and universe counts unresolved.** psx-dps 38 sectors vs psxdata 37; ~496 trading symbols vs ~1,029 listed instruments vs 1000+ tickers. Preserved with sources in all docs; Layer 4 / registry must record which list any aggregate used. Next action: Phase 04 reconciliation with dated evidence; no module may claim full-market completeness until then.
- **G-04 — Versions and model unpinned.** Only Python 3.12.3 and Node v24.22.1 are verified present; Docker, psql, redis-cli are verified NOT installed. No library version is pinned in Phase 1, and no specific Ollama open-weight model is selected (licence, local fit, tool-calling accuracy, auditability, offline operation are the ADR-007 evaluation gates). Next action: Phase 02 setup pinning + model evaluation; do not pin a model on an unverified benchmark.
- **G-05 — SBP/PBS direct fetches failed in Team 2's session.** The failures were fetch errors, not site findings. Next action: retry via a live-browser check (parent-agent route — generic subagents cannot operate a live browser) if SBP/PBS machine-use is to be verified; until then both remain UNVERIFIED.
- **G-06 — FRED AI/caching gate.** FRED is gated out of AI training, caching, and commercial output until the full current Terms are directly re-read and the specific use is cleared in writing (Team 2 finding, PARTIALLY VERIFIED via search snippet, not a directly read Terms page). Next action: direct Terms read + written clearance check before any FRED use.
- **G-07 — MinIO adoption unresolved, correctly.** MinIO is OPTIONAL and NOT ADOPTED: its community build is reported archived/read-only (April 2026) with no upstream fixes, and vendor AIStor Free is proprietary and licence-key-gated. The project works fully without MinIO. Next action: re-verify status before any future adoption; never adopt a paid MinIO/AIStor tier under PKR 0.
- **G-08 — No measured performance, price, or coverage figures.** No benchmark, hosting price, backtest result, or company figure is asserted in this document set. Any future figure must be labelled with its measurement method and date. This is compliance with the brief, not a gap to fill by estimation.
