### Integrity rules, as enforced (not merely documented)

- Never overwrite observations or published/revised statements:
  trigger-enforced (see trigger counts above).
- Never mark unverified as verified without evidence:
  `upgrade_quality_status` requires evidence for ANY transition
  into VERIFIED/PARTIALLY_VERIFIED (audit M1 fix).
- Never delete provenance; never silently merge conflicts:
  conflicts kept side-by-side (unique grain per source; NULL
  source hole closed by NOT NULL, audit H3).
- Missing is never zero; collection time is never observation
  time (separate columns, helpers, tests).
- Paper-trading portfolios ONLY: no broker, brokerage, order,
  api_key, password, secret, token or credential columns exist
  on any of the 54 tables (full-column scan test, audit L4 fix).
- No secrets in logs: agent_executions/agent_outputs carry no
  secret-named columns; the only secret-like string in the tree
  is the Phase 2 clearly-labelled fake test fixture, asserted
  never to appear in responses.
